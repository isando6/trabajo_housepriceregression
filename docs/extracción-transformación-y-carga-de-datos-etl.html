Modelo de regresión lineal para la predicción del precio de vivienda: conjunto ‘House Price Regression’

2 Extracción, transformación y carga de datos (ETL)

Antes de realizar cualquier análisis exploratorio o estadístico, es necesario garantizar que los datos con los que se trabajará sean confiables, estén completos y en un formato adecuado para su manipulación.

Este proceso, conocido como ETL (Extracción, Transformación y Carga), constituye la base de todo análisis de datos. Si esta etapa se realiza de forma deficiente, cualquier resultado o interpretación posterior, por más sofisticado que resulte siendo, quedará comprometido. De esta manera, se realizará la carga del conjunto de datos house_price_regression_dataset.csv, la identificación de valores faltantes y duplicados y, como último paso, la verificación de que cada variable se mueva dentro de rangos plausibles antes de iniciar el análisis exploratorio que se desarrollará más adelante.

2.1 Instalación de librerías

En primer lugar, se cargan las librerías necesarias para el desarrollo de este trabajo: tidyverse para la manipulación y visualización de datos mediante una sintaxis basada en el operador pipe (%>%); Amelia, utilizada para la detección visual de datos faltantes a través de la función missmap(); moments, que permite calcular medidas de forma de la distribución como la asimetría y la curtosis; patchwork, empleada para combinar múltiples gráficos de ggplot2 en una sola figura; GGally, que amplía las capacidades de visualización de ggplot2 con funciones como ggpairs() y ggcorr() para el análisis de relaciones entre variables; y Hmisc, utilizada específicamente para calcular, en un solo paso, la matriz de correlación junto con la matriz de p-valores correspondiente a cada pareja de variables predictoras mediante la función rcorr().

library(Amelia)
library(tidyverse)
library(dplyr)
library(moments)
library(patchwork)
library(GGally)
library(Hmisc)
library(kableExtra)

2.2 Carga del conjunto de datos house_price_regression_dataset

Se procede a cargar el conjunto de datos, correspondiente a información de viviendas residenciales individuales, con variables estructurales (superficie, habitaciones, baños, garaje), temporales (año de construcción), de entorno (calidad del vecindario) y el precio de venta observado.

   data <- read_csv("house_price_regression_dataset.csv")

2.4 Identificación de valores faltantes (NA)

Uno de los pasos más importantes de esta etapa es identificar la presencia de valores faltantes. En este contexto, ignorar los datos faltantes podría sesgar las estadísticas descriptivas y los análisis posteriores, especialmente si la ausencia de datos no ocurre de forma aleatoria (por ejemplo, si ciertas viviendas reportan sistemáticamente menos información sobre alguna característica). Así, se cuantifica primero el número de valores faltantes por columna:

data %>%
  summarise(across(everything(), ~sum(is.na(.)), .names = "NA_{.col}")) %>%
  knitr::kable(caption = "Conteo de valores faltantes por columna") %>%
  kableExtra::kable_styling(bootstrap_options = c("striped", "hover", "condensed", "bordered"),
                             full_width = FALSE)

2.6 Verificación de rangos plausibles

Antes de avanzar al análisis exploratorio, se revisa que cada variable se mueva dentro de un rango razonable para un conjunto de viviendas residenciales, lo que permite descartar errores de digitación o valores negativos imposibles (como una superficie o un precio menor a cero).

rangos <- data.frame(
  Variable = c("Neighborhood_Quality", "Year_Built", "House_Price", "Lot_Size", "Square_Footage"),
  Minimo   = c(min(data$Neighborhood_Quality), min(data$Year_Built), min(data$House_Price),
               min(data$Lot_Size), min(data$Square_Footage)),
  Maximo   = c(max(data$Neighborhood_Quality), max(data$Year_Built), max(data$House_Price),
               max(data$Lot_Size), max(data$Square_Footage))
) %>%
  mutate(
    Minimo = format(round(Minimo, 2), big.mark = ",", scientific = FALSE, trim = TRUE),
    Maximo = format(round(Maximo, 2), big.mark = ",", scientific = FALSE, trim = TRUE)
  )

knitr::kable(rangos, caption = "Rangos observados por variable", align = "lrr") %>%
  kableExtra::kable_styling(bootstrap_options = c("striped", "hover", "condensed", "bordered"),
                             full_width = FALSE)
