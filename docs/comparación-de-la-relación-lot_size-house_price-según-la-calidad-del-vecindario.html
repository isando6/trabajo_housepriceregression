Modelos de regresión lineal simple y múltiple para la predicción del precio de vivienda: conjunto ‘House Price Regression’

9 Comparación de la relación Lot_Size-House_Price según la calidad del vecindario

Para saber si la calidad del vecindario cambia la forma en que el tamaño del terreno se relaciona con el precio de la vivienda, hay que separar las observaciones según ese entorno y preguntarse, grupo por grupo, si la relación se sostiene o no.

data <- data %>%
  mutate(
    Calidad_Grupo = case_when(
      Neighborhood_Quality <= 3 ~ "Baja",
      Neighborhood_Quality <= 7 ~ "Media",
      Neighborhood_Quality >= 8 ~ "Alta"
    ),
    Calidad_Grupo = factor(Calidad_Grupo, levels = c("Baja", "Media", "Alta"))
  )

data %>%
  count(Calidad_Grupo) %>%
  mutate(Rango = c("1 - 3", "4 - 7", "8 - 10"),
         Porcentaje = paste0(round(100 * n / sum(n), 1), "%")) %>%
  select(Calidad_Grupo, Rango, n, Porcentaje) %>%
  kableExtra::kbl(row.names = FALSE,
                  col.names = c("Grupo de calidad", "Neighborhood_Quality", "Número de viviendas", "Porcentaje")) %>%
  kableExtra::kable_styling(bootstrap_options = c("striped", "hover", "condensed", "bordered"),
                             full_width = FALSE)
Grupo de calidad Neighborhood_Quality Número de viviendas Porcentaje
Baja 1 - 3 281 28.1%
Media 4 - 7 411 41.1%
Alta 8 - 10 308 30.8%

El grupo de calidad media concentra a más de la mitad de las viviendas (411), mientras que Baja (281) y Alta (308) quedan más equilibrados entre sí, una consecuencia esperable de agrupar una escala de 1 a 10 en solo tres bloques desiguales (1-3, 4-7, 8-10).

baja  <- data %>% filter(Calidad_Grupo == "Baja")
media <- data %>% filter(Calidad_Grupo == "Media")
alta  <- data %>% filter(Calidad_Grupo == "Alta")

Con los tres grupos ya separados, empecemos por el extremo inferior de la escala y vayamos subiendo.

9.1 Grupo: Baja calidad

baja %>%
  ggplot(aes(x = Lot_Size, y = House_Price)) +
  geom_point(alpha = 0.4, color = "#8fa8a0") +
  geom_smooth(method = "lm", formula = y ~ x, se = TRUE, color = "#2c5f6e", fill = "#2c5f6e") +

data.frame(r = round(with(baja, cor(Lot_Size, House_Price)), 4)) %>%
  kableExtra::kbl(row.names = FALSE, col.names = "Coeficiente de correlación de Pearson (r)") %>%
  kableExtra::kable_styling(bootstrap_options = c("striped", "hover", "condensed", "bordered"),
                             full_width = FALSE)
Coeficiente de correlación de Pearson (r)
0.0283

De las 281 viviendas en vecindarios de baja calidad, la nube de puntos cubre todo el rango de precios (desde poco más de USD 110.000 hasta cerca de USD 1.1 millones) para cualquier tamaño de terreno, sin ninguna inclinación perceptible; la recta ajustada es prácticamente horizontal y su banda de confianza es muy ancha.

Antes de usar lm(), se calculan los coeficientes a mano con las fórmulas de mínimos cuadrados, \(\hat\beta_1 = S_{xy}/S_{xx}\) y \(\hat\beta_0 = \bar{y} - \hat\beta_1 \bar{x}\), para luego compararlos con los que entrega R.

X <- baja$Lot_Size
Y <- baja$House_Price
n_baja <- length(X)

x_bar <- mean(X); y_bar <- mean(Y)
Sxx_baja <- sum((X - x_bar)^2)
Sxy_baja <- sum((X - x_bar) * (Y - y_bar))

beta1_baja <- Sxy_baja / Sxx_baja
beta0_baja <- y_bar - beta1_baja * x_bar

modelo_baja <- lm(House_Price ~ Lot_Size, data = baja)

data.frame(
  Parametro = c("Intercepto (β₀)", "Pendiente (β₁)"),
  Manual    = round(c(beta0_baja, beta1_baja), 2),
  Lm        = round(coef(modelo_baja), 2)
) %>%
  kableExtra::kbl(row.names = FALSE,
                  col.names = c("Parámetro", "Cálculo manual", "lm()")) %>%
  kableExtra::kable_styling(bootstrap_options = c("striped", "hover", "condensed", "bordered"),
                             full_width = FALSE)
Parámetro Cálculo manual lm()

El cálculo manual (\(\hat\beta_1\) = 5.519, \(\hat\beta_0\) = 608.681) coincide exactamente con lo que entrega lm(), confirmando que la fórmula de mínimos cuadrados y la función de R llegan al mismo resultado. El error estándar de \(\hat\beta_1\) (11.687) es más de dos veces mayor que el propio coeficiente, una primera señal de que esta pendiente no se va a sostener frente a la prueba de hipótesis.

El intervalo de confianza al 95% para \(\beta_1\) es (−17.486, 28.524), contiene el cero, y la prueba de hipótesis no se rechaza (t = 0.47; p = 0.637). La tabla ANOVA llega a la misma conclusión desde otro ángulo (F = 0.22; p = 0.637). En el grupo de vecindarios de baja calidad, no hay evidencia de que el tamaño del terreno tenga ningún efecto sobre el precio.

Con la baja calidad ya resuelta, sin relación alguna, la pregunta natural es si subir un escalón en la escala cambia algo.
